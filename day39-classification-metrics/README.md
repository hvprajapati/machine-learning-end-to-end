# Day 39 — Classification Metrics

Accuracy, confusion matrix, precision, recall and F1, for binary and multi-class problems.

## Teaching order

| # | Notebook | What it covers |
|:-:|---|---|
| 1 | [`01-classification-metrics-binary.ipynb`](01-classification-metrics-binary.ipynb) | Heart disease: logistic regression vs decision tree; accuracy, confusion matrix, precision, recall, F1 |
| 2 | [`02-classification-metrics-multiclass-iris.ipynb`](02-classification-metrics-multiclass-iris.ipynb) | Iris (3 classes): multi-class confusion matrix, precision and recall per class |
| 3 | [`03-classification-metrics-multiclass-mnist.ipynb`](03-classification-metrics-multiclass-mnist.ipynb) | MNIST digits (10 classes): confusion matrix, weighted precision/recall/F1, `classification_report` |

Note: these notebooks were written on Kaggle and read data from `/kaggle/input/...` (heart disease UCI, Iris, digit recognizer). Download those datasets and change the path to run them locally.
